# C Practice Codes

A collection of **50 C practice programs** that I wrote while learning **CL-1002 Programming Fundamentals** in my first semester at **FAST-NUCES Peshawar Campus** (Software Engineering). They cover the syllabus from Sessional 1 to Sessional 2, up to functions.

## What's Inside
All programs are named `practice code 1` to `practice code 50`. Each file is a single, self-contained C program.

Topics covered across these programs:
- Variables, data types, `printf` and `scanf`
- Operators and typecasting
- `if`, `if/else`, nested `if/else`, and `else if` ladders
- `for`, `while`, and `do-while` loops
- Nested loops and patterns
- Functions

## How to Run
```bash
gcc "practice code 1.c" -o output -lm
./output
```
(`-lm` is needed only for programs that use `math.h`)
